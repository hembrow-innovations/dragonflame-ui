# Style as data

## This is working when

Style is StyleSheet-shaped objects.

## Nested locations

- **StyleSheet shape**: this is working when style is StyleSheet-shaped objects.
  - bet: try style as data; pivot if style becomes a CSS language in the framework
- **Native feed**: this is working when on native those objects feed layout and paint.
  - bet: try data into Taffy and paint; pivot if they become a CSS engine on native
- **Web may use CSS**: this is working when web may use CSS because the browser already has it. See [[location-31-web-layout]]
  - bet: try CSS on web and data on native; pivot if one CSS engine is required for both hosts
