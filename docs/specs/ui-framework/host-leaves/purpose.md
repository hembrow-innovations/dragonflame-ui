# Host leaves purpose

## Job

The six host leaves already mount. Nested honesty is not HTML, and not every UIKit class as the leaf set.

Planning sitting [[rounds-144-host-leaves-honesty]] and [[intent]]:

- **Honesty nested bets**: not HTML, and not every UIKit class as the leaf set. The six leaves are already named.
- **Intent**: one component model, two hosts.
- **Architecture**: shared code is composite components. Host leaves are a closed set.

## In scope

Child destination sentences from [[location-32-host-leaves]]:

- **Closed set**: the small host primitive set is view, text, image, scroll, text input, and pressable.
- **Not HTML**: not HTML as the leaf set.
- **Not every UIKit class**: not every UIKit class as the leaf set.

This area's oracles prove this checkout does not add HTML leaves, and does not treat every UIKit class as the leaf set. They do not prove view, text, image, scroll, text input, or pressable. [[purpose-leaf-kit]] already locks those. [[purpose-leaf-kit]] asserts `leaf-kit.set:forbid-html` without tests; this folder owns the lock.
